# Phase 7: Multiball Fix + Arena Modifiers

## Goal
Fix the multiball scoring bug (non-main ball scoring wipes all balls). Add two permanent arena modifiers: wind zones (directional force fields) and bumper chaos (pinball bumpers).

## Tasks

### T1: Fix Multiball Scoring Bug
**Files**: lib/logic.js  
**Description**: When an extra (non-main) ball scores, it currently calls `startRound()` which resets all balls via `NP.balls = [NP.ball]`. Fix: extra balls should only remove themselves — the main ball and other active extra balls stay in play. Only the main ball triggers a round reset.

### T2: Wind Zones — Directional Force Fields
**Files**: lib/engine.js, lib/render.js, lib/logic.js  
**Description**: 3 horizontal wind strips spanning the full court width. Each strip has a direction (left or right) that applies a gentle `vx` force to any ball passing through it. Visual: semi-transparent colored strip with animated arrows. Zones are permanent arena features.

### T3: Bumper Chaos — Pinball Bumpers
**Files**: lib/engine.js, lib/render.js, lib/logic.js  
**Description**: 3-4 static circular bumpers positioned on the court. When a ball collides with a bumper, it bounces off with amplified speed. Visual: neon-glowing circles with a subtle pulse animation. Bumpers are permanent arena features.

## Dependency Graph
```
T1 (standalone multiball fix) — no dependencies
T2 (wind zones) — no dependencies, different files than T3
T3 (bumpers) — no dependencies, different files than T2
All three can run in parallel.
```
