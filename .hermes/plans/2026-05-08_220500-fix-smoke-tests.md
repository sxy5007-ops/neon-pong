# Fix Smoke Tests for Modularized Codebase

## Goal
Update `tools/smoke-test.js` to work with the modularized codebase where game logic lives in `lib/` files instead of a single `game.js`. Runs all 5 existing tests against the `NP` namespace.

## Current Problem
`tools/smoke-test.js` reads `game.js` from the project root, which no longer exists (it's only in `modular_backup/`). The tests reference old internal variable names (`state`, `DIFFICULTY`, `POWER_UP_SIZE`, etc.) that were replaced by `NP.state`, `NP.DIFFICULTY`, `NP.POWER_UP_SIZE`, etc.

## Plan

### Step 1: Update file loading
- Change `gamePath` from `../game.js` to `../lib/engine.js`
- Load all 6 script files in the same order as `index.html`:
  1. `lib/engine.js` - state, constants, save
  2. `lib/audio.js` - audio engine
  3. `lib/powerups.js` - power-up system
  4. `lib/render.js` - rendering
  5. `lib/logic.js` - game logic, AI, loop
  6. `main.js` - DOM binding, event listeners, init
- Concatenate all 6 files into one source string before eval

### Step 2: Update test API references
